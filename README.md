# AD Calc - Simulador de Preços Públicos CAP/DEPROT

Simulador web PWA para cálculo de preços públicos com contador compartilhado em tempo real.

## 🚀 Funcionalidades

- ✅ Cálculo automático de 18 tipos de processos CAP/DEPROT
- ✅ Contador pessoal da sessão (diário)
- ✅ **Calculômetro REAL** - Soma de TODOS os usuários (JSONBin.io)
- ✅ Botão para copiar valor no formato internacional
- ✅ Design minimalista e responsivo
- ✅ Funciona offline com sincronização automática
- ✅ Atualização quase em tempo real (30 segundos)
